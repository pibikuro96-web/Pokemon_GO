# Pokémon GO コンプチェッカー

2026年11月6日現在の個人用図鑑・入手管理サイトです。静的サイトのため、`index.html` を開くかGitHub Pagesで配信できます。**このリポジトリはprivateのため、GitHub Pagesを公開できる状態かどうかは別途設定の確認が必要です。**

## 主要ファイル

- `index.html`: 検索、7カテゴリ、入手チェック、バックアップ、画像・不足リストへのアクセス
- `catalog-data.json`: 図鑑/フォルム/衣装/性差の**3,110項目を一括保存**。ページ表示時に外部APIから図鑑データを取得しません
- `atlas-index.json`: スクリーンショットで実画像が確認できた全国図鑑番号の索引
- `images/pogo-normal-atlas.webp`: 通常図鑑の画像951枚を図鑑番号順のタイルへ変換（約741KB）
- `images/pogo-shiny-atlas.webp`: 色違い図鑑の画像799枚を図鑑番号順のタイルへ変換（約576KB）
- `missing-pokemon.csv`: 日本語名付きの画像不足一覧。228種、通常74種、色違い226種
- `assets-index.json`: GO/HOME外部画像のバックアップ参照用索引
- `gender-data.json`: オス・メス差分103項目のマスター

## 不足画像リスト

- [通常・色違い図鑑の不足228種（日本語名付き）](missing-pokemon.csv)：図鑑番号、ポケモン名、通常／色違い画像の有無
- [全カテゴリの不足画像1,790枠（詳細）](missing-all-image-slots.csv)：フォーム・衣装・性別差分も含め、画像の種類ごとに表示

全1,025種のうちローカル写真を確認できたのは通常951種・色違い799種（合計1,750枠）です。画像不足は未所持を意味しません。参考画像を外部ソースから表示できる場合でも、**ユーザー提供画像としては不足**と集計します。

## 写真について

Googleドライブ「ポケモンGO」フォルダに保存された110枚の`IMG_5908.PNG`〜`IMG_6018.PNG`（`IMG_6000`なし）を元に、図鑑番号ごとに画像を切り出しました。元のスクリーンショットは変更していません。画像がない枠、シルエット、画面外のポケモンは不足として集計し、同じ姿を推測で貼り付けていません。

画像割当は自動検出を併用した**暫定照合結果**です。数字と画像の取り違えを発見した場合は修正が必要です。写真がないことはゲーム内で未所持であることを意味しません。未実装・色違い未解禁・図鑑範囲外を含む可能性があります。

## 外部通信

- 通常図鑑/色違い図鑑の写真が確認できた計1,750枠は、リポジトリ内のWebP画像を参照します。1匹ごとに外部サイトへ問い合わせません
- ほかのフォルム・衣装・性差、アップロード画像が見つからないポケモンは、現在もPokeMiners/PokeAPI等の画像を**補助的に**参照することがあります
- 図鑑・衣装の文字データは`catalog-data.json`にまとめてあるため、通常のページ表示時に外部データAPIを参照しません

## 保存・引越し時の注意

チェック情報はブラウザの`localStorage`（キー `pogo-personal-collection-v1`）に保存します。別端末・別ドメインへは自動同期しません。設定の「バックアップを保存（JSON）」から書き出しておくことを推奨します。公開URL・オリジンが変わる場合はバックアップを復元してください。
