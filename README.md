# Pokémon GO コンプチェッカー

個人用の入手・コンプリート管理サイトです。GitHub Pages: https://pibikuro96-web.github.io/Pokemon_GO/

## データスナップショット（2026年11月9日）

- 図鑑・姿・衣装・性差・色違い・メガシンカ・キョダイマックスの登録件数（`catalog-data.json`）: **3,846件**、**14カテゴリ**。別フォルム側に参照表示する「対象外」カードはこの件数に含めません。
- 通常色と色違いの別フォルム: **各334件**（別途「対象外」の参照表示あり）。全国図鑑と同じ「通常の姿」は別フォルムで二重に数えません。
- パッチールの模様: **01〜09のみ**。10〜20は通常・色違いとも対象から削除しました。ジガルデの50％／パーフェクトをそれぞれ追加し、未解禁の色違いは分けています。
- ピカチュウ衣装の登録候補: **通常104件・色違い104件**。2026年11月7日未明時点の分類は通常色102件登場済み・2件予定、色違い99件解禁照合済み・1件確認中（シンガポール）・2件未解禁（コピー、ドクター）・2件予定です。
- その他の衣装: **通常色227件・色違い227件**を登録。うち実装・解禁確認済み扱いは通常色227件、色違い218件です。バケッチャ・パンプジンの2022年ハロウィン衣装は、それぞれ**こだま／ちゅうだま／おおだま／ギガだま**の4サイズを独立してチェックできます。旧パンプジンのチェックIDは「ちゅうだま」に維持しています。
- デフォルトの分母は解禁・実装確認済み**3,246枠**。未実装・未確認も集計対象に含める設定では最大**3,786枠**です（性差は♂♀両方で1枠、色違い未解禁の衣装は除外）。
- 2026年11月6日に初登場した**ジャケットを身にまとったカイリキー**（通常色・色違い）を公式イベント情報に基づき登録済みに変更しました。対応するGO衣装画像は通常色・色違いとも索引に収録済みです。キョダイマックスカイリキーとは別の衣装です。
- 未実装・解禁未確認の別フォルムは表示スイッチをオフにすると非表示、オンにすると表示します。表示されるフォルムは追加ページを操作せず最後まで閲覧可能です。

## メガシンカ・キョダイマックス（2026年11月9日）

- メガシンカ／ゲンシカイキは**通常色97候補・色違い97候補**を収録し、**各63種類を実装確認済み**とします。対象にはカイオーガ・グラードンのゲンシカイキを含み、メガミュウツー X／Y、メガライチュウ X／Yはそれぞれ独立した項目です。
- キョダイマックス（G-MAX）は**通常色33候補・色違い33候補**で、通常色18種類、色違い17種類を実装確認済みとします。キョダイマックスインテレオンは実装済みですが、**色違いは未解禁**として扱います。2026年11月6日登場のキョダイマックスジュラルドンとその色違いを含みます。
- 通常のメガシンカは「自分のポケモンでそのメガシンカを経験した」、色違いメガシンカは「色違い個体をその形態にメガシンカさせた」、通常G-MAXは「キョダイマックス可能な個体を入手した」、色違いG-MAXは「色違いのキョダイマックス可能個体を入手した」をチェック基準とします。一般のダイマックス個体はG-MAXに含めません。
- 未実装のメガシンカ34種・キョダイマックス15種（色違いはそれぞれ34種・16種）は、「未実装・未確認も表示」をオンにしたときに候補として表示します。新カテゴリには従来の入手チェック、集計、検索、地域絞り込み、集計対象外、JSON保存・復元、リロード時の位置復元が適用されます。
- 画像はPokeMinersの正確な**Pokémon GO透過素材**のみを照合します。確認済みの全161枠は通常色・色違いそれぞれの対応画像が索引に存在します。未実装候補は該当GO画像がなければ「GO画像未取得」のまま表示します。
- [メガ・G-MAX監査CSV](mega-gmax-audit.csv)には全260行の実装状況、色違い解禁、画像対応を記録しました。実装情報は[BulbapediaのGO実装年表](https://bulbapedia.bulbagarden.net/wiki/List_of_Pok%C3%A9mon_by_availability_in_Pok%C3%A9mon_GO)と[Pokémon GO公式ニュース](https://pokemongo.com/news)、候補フォルムは[Z-Aのメガシンカ一覧](https://www.serebii.net/legendsz-a/megaevolutions.shtml)を基準にしています。

## ピカチュウの実装日順と画像の照合

- 提供された[コスチュームピカチュウ管理表（Google Sheets）](https://docs.google.com/spreadsheets/d/1NPnnuVkjtA9N6y2tnITIEal4XSrt4ahgtU-Bqi2U460/edit)の**シート1**を読み取り、**画像103行・実装日101件・今後予定の3件**と衣装104種類を対応付けました。シートに用意された番号105〜120は空欄の予約枠で、実装済み衣装とみなしません。
- [画像と実装順の対応JSON](pika-costume-order-reference.json)にシート上の行番号、衣装ID、初実装日、画像の照合状態を保存しています。通常色・色違いは同じ衣装順で表示し、カードにも初実装日を表示します。
- シートの色違い実装日は未入力のため、**色違いの個別解禁日は確定扱いにしていません**。色違いの解禁判定は[Pokéらく衣装一覧](https://pokemongo-raku.com/post22566)、[9db](https://9db.jp/pokemongo/data/8968)、[Pokémon GO公式ニュース](https://pokemongo.com/ja/news)などから区別しています。
- [104件の衣装照合CSV](pika-costume-audit.csv)で実装順・日付・通常色／色違い判定・画像存在・チェックIDを追跡できます。なお衣装ピカチュウ105件とする他サイトには**TCG青キャップの重複掲載**があり、104種類の異なる姿を採用しました。
- 2026年11月7日にシンガポール限定ピカチュウ（ブルー）の登場をPokémon GO公式発表で確認し、通常色を実装済みに変更しました。色違いは未確認です。今後の予定はフィリピン2027-01-23、タイ2027-02-13で、開催後の自動再判定は現在行っていません。

- ルナアーラの色違い（No.792）は2026年8月19日の伝説レイドで初登場したため、2026年11月9日に「確認中」から「実装済み」に修正しました。

## フォルムの監査・適用範囲

- [フォルム監査CSV](form-audit.csv): 登録済みの357件すべてを、通常色／色違い／GO画像／リージョン／未解禁で比較します。
- GO本編の別フォルム・リージョンと、Pokémon GO独自コスチュームを分離しています。メガシンカ、ゲンシカイキ、ダイマックス、キョダイマックス、シャドウ等の一時的・戦闘時の変化は本監査の別フォルムとは別機構としています。
- 「すべてのゲーム本編フォルムがPokémon GOで使える」ことを意味しません。未実装・解禁未確認候補もあるため、個々の公式解禁は別途検証が必要です。

## 画像と不足管理

- 公開ページでは全カテゴリともPokémon GOゲーム由来の透過画像索引を参照し、ローカルの切り抜きアトラスや他作品の画像には置き換えません。画像未取得は未所持を意味しません。
- 過去に作成した[図鑑の不足画像一覧](missing-pokemon.csv)と[全姿のローカル画像未照合一覧](missing-all-image-slots.csv)は、旧ローカル写真の監査資料として残しています。現在の**実装済み衣装の正確なGO透過画像未取得は20枠**（バケッチャ8、パンプジン8、ガラルポニータ2、ガラルジグザグマ2）で、[現行の不足画像一覧](missing-go-costume-images.csv)に記録しています。衣装のない通常のGO画像では代用しません。
- 画像ファイルがゲーム内の未実装・未解禁の姿にも存在し得るため、画像の存在を出現・色違い解禁の証拠とはしません。

## データ保存・端末間共有

- 入手チェックはブラウザの `localStorage` キー `pogo-personal-collection-v1` に保存します。同じURLでも別端末には**自動同期されません**。
- 現時点では設定の「バックアップを保存（JSON）」からファイルをiCloud Drive/Google Drive等に置き、別端末で「バックアップを読み込む」により手動移行できます。インポート時にはその端末内のチェック結果を置き換えます。
- 端末間自動同期は導入しない方針です。必要な場合のみJSONバックアップによる手動移行を利用します。
- ページをリロードしても、同じブラウザのタブ内では開いていたカテゴリ・検索条件・絞り込み・展開件数・スクロール位置を `sessionStorage` から復元します。端末や別タブには引き継ぎません。
- 旧 `html_pages/pokemon-go-checker` は変更していません。
