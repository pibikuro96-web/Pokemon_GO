# Pokémon GO コンプチェッカー

2026年11月6日現在の個人用図鑑・入手管理サイトです。静的サイトのため、`index.html` を開くかGitHub Pagesで配信できます。公開URL：**https://pibikuro96-web.github.io/Pokemon_GO/**（GitHub Pages）

## 主要ファイル

- `index.html`: 検索、8カテゴリ、入手チェック、バックアップ、画像・不足リストへのアクセス
- `catalog-data.json`: 図鑑/フォルム/衣装/性差の**3,509項目を一括保存**。ページ表示時に外部APIから図鑑データを取得しません
- `atlas-index.json`: スクリーンショットで実画像が確認できた全国図鑑番号の索引
- `images/pogo-normal-atlas.webp`: 通常図鑑の画像951枚を図鑑番号順のタイルへ変換（約741KB）
- `images/pogo-shiny-atlas.webp`: 色違い図鑑の表示有効な画像797枚を図鑑番号順のタイルへ変換（約576KB）
- `missing-pokemon.csv`: 日本語名付きの画像不足一覧。230種、通常74種、色違い228種
- `assets-index.json`: GO/HOME外部画像のバックアップ参照用索引
- `gender-data.json`: オス・メス差分103項目のマスター
- `availability-review.csv`: 未実装389件、実装未確認249件、衣装色違い未確認327件の再確認リスト（計965件）

## 実装状況とコンプリート率（2026年11月6日）

- 全国図鑑1,025種のうち、**実装確認済み959種**、未実装66種。
- 通常色違いは**確認済み896種**、種族未実装66種、それ以外の色違い解禁を未確認としたもの63種。896種は現時点の照合結果であり、全件の公式個別確認が完了した数字ではありません。
- リージョン・別フォルム・衣装は、実装確認済みと資料不足の「確認中」を区別しています。衣装ごとの色違い解禁は個別に未確認のため、現在のコンプ率に含めていません。
- 上部・カテゴリ別・地方別の通常のコンプ率は実装確認済み・集計対象外を除く **合計3,075チェック枠**（性差は♂/♀別々）を分母にします。地方/カテゴリの絞り込みでは対象範囲内を表示します。
- **「未実装・未確認も表示」**をオンにすると、未実装・確認中の項目と衣装の色違い未確認も進捗に加算します。このときの集計対象は最大**4,042チェック枠**です。オンオフで分母は切り替わりますが、入手チェックは削除されません。達成率は小数第2位まで表示します。
- 判定の参考資料： [Hailey-Ross/hailsDotGO 2026年7月の実装・色違い基準](https://github.com/Hailey-Ross/hailsDotGO/blob/main/internal/pogodata/fallback/shiny_baseline.json)、[Bulbapedia Pokémon GO availability](https://bulbapedia.bulbagarden.net/wiki/List_of_Pok%C3%A9mon_by_availability_(GO))、[Pokémon GO公式ニュース](https://pokemongo.com/news)。その後の2026年イベント実装情報と2026年11月6日に本編の通常姿・追加フォルムと日本語名称、並び順を補完しました。データは固定スナップショットで、毎日自動更新はしません。
- 未実装・資料不足の判定を点検する場合は [実装状況の確認リスト](availability-review.csv) を参照してください。

## 不足画像リスト

- [通常・色違い図鑑の不足230種（日本語名付き）](missing-pokemon.csv)：図鑑番号、ポケモン名、通常／色違い画像の有無
- [全カテゴリの不足画像2,294枠（詳細）](missing-all-image-slots.csv)：フォーム・衣装・性別差分も含め、画像の種類ごとに表示

全1,025種のうちローカル写真を確認できたのは通常951種・色違い797種（合計1,748枠）です。画像不足は未所持を意味しません。参考画像を外部ソースから表示できる場合でも、**ユーザー提供画像としては不足**と集計します。

## 写真について

Googleドライブ「ポケモンGO」フォルダに保存された110枚の`IMG_5908.PNG`〜`IMG_6018.PNG`（`IMG_6000`なし）を元に、図鑑番号ごとに画像を切り出しました。元のスクリーンショットは変更していません。画像がない枠、シルエット、画面外のポケモンは不足として集計し、同じ姿を推測で貼り付けていません。

画像割当は自動検出を併用した**暫定照合結果**です。数字と画像の取り違えを発見した場合は修正が必要です。写真がないことはゲーム内で未所持であることを意味しません。未実装・色違い未解禁・図鑑範囲外を含む可能性があります。

## 外部通信

- 通常図鑑/色違い図鑑の写真が確認できた計1,748枠は、リポジトリ内のWebP画像を参照します。1匹ごとに外部サイトへ問い合わせません
- ほかのフォルム・衣装・性差、ローカル画像が見つからないポケモンは、現在もPokeMiners/PokeAPI等の画像を**補助的に**参照することがあります
- 図鑑・衣装の文字データは`catalog-data.json`にまとめてあるため、通常のページ表示時に外部データAPIを参照しません

## 保存・引越し時の注意

チェック情報はブラウザの`localStorage`（キー `pogo-personal-collection-v1`）に保存します。別端末・別ドメインへは自動同期しません。設定の「バックアップを保存（JSON）」から書き出しておくことを推奨します。公開URL・オリジンが変わる場合はバックアップを復元してください。

旧`html_pages/pokemon-go-checker`は変更せず、こちらが今後の作業先です。

## フォルムの整理（2026年11月6日）

- 全国図鑑の「通常」は1,025種の代表姿1つずつです。別フォルム／色違いフォルムは通常姿も含めて各463枠です。
- デオキシス、バスラオ、ダルマッカ・ヒヒダルマ、ギラティナ、トロス三兄弟、ゲノセクトなどの欠落姿を追加しました。アンノーン、シキジカ、メブキジカ、ロトム、ポワルン、フラベベ系統、トリミアンなどに指定順の`sortOrder`を設定しました。パッチールの画像キーは従来どおり00始まりですが、表示番号を1〜20に変更しました（チェックIDは維持）。
- コフキムシ・コフーライの地域別の図案（各20枠）は、実際には外観差がないため別フォルム対象から除外しました。ビビヨンの模様20種は保持しています。
- 未確認・未実装の姿もカタログに記録しますが、ポケモンGOでの入手可否を確認済みという意味ではありません。マホイップ等は本編差分として保管し、実装までは計算対象外（表示切替でのみ含む）です。

## 色違い画像・性差タブの更新（2026年11月6日）

- 全国図鑑の色違いNo.647 ケルディオ、No.648 メロエッタ、No.649 ゲノセクトは、切り出し写真（または不適切な代表姿）を使用せず、PokeMinersの該当する色違いGOアイコンを優先して表示します。該当する写真のローカル割当は無効化し、元の画像ファイルは削除しません。
- 別フォルム・色違い別フォルムは、実装未確認・未実装の区別を維持したまま全国図鑑No.1024まで全463枠を一覧に表示します。進捗集計では通常どおり実装確認済みだけを対象とし、表示切替をオンにすると未実装・未確認を含めます。
- 色違いオス・メス差分の専用タブ（103種、オス・メス合計206チェック枠）を追加し、既存の性差タブと独立して保存します。画像は該当するGOの色違い性差スプライト、またはPokeAPI HOMEの色違いメス用画像を優先します。
- 色違いケルディオ・メロエッタの解禁は、2025年のPokémon GO公式ニュースで確認した範囲をフォルムの集計に反映しました。
